# Python Break Continue Pass

## Explanation

Python provides special statements to control the execution of loops:

* `break` stops the loop completely.
* `continue` skips the current iteration and moves to the next iteration.
* `pass` does nothing and acts as a placeholder.

## Problem Statement

Write a Python program that demonstrates the use of `break`, `continue`, and `pass` statements.

## Features

* Demonstrates `break`
* Demonstrates `continue`
* Demonstrates `pass`
* Uses `for` loops
* Shows how loop execution can be controlled

## How It Works

The program contains three separate examples.

### Break

The loop stops when the number reaches `5`.

### Continue

The number `5` is skipped using `continue`.

### Pass

The `pass` statement is used when the number reaches `5`, allowing the loop to continue normally.
